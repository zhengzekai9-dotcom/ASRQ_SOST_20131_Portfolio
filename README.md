### Why reproducibility Matters?
Reproudciblity means other researchers can search use the same data code to obtain the same result. Unlike the natural sciences, social science rarely benefits from controlled experiments, and findings depend heavily on researchers’ choices about data cleaning, variable selection and model specification. Without transparency, it is impossible to know whether a result reflects reality or simply those choices
